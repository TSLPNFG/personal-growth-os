# File Organization

所有真实数据存放在 private/workspace。goals 保存目标；learning 保存学习；knowledge 保存知识；journal 保存事件原文与整理；reflections 保存跨期复盘；habits 保存习惯；prompts 保存私人提示词；decisions 保存选择；patterns 保存候选模式及来源；memory 保存个人理解摘要；handoff 保存任务状态。

按日期或周期命名，来源用相对链接。一份内容仅有一个完整归属位置。private/legacy 是旧资料快照，不自动迁入当前模型。公共目录仅允许通用方法、空白模板和独立虚构示例。

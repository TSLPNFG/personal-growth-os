# 完全虚构的示例

以下“练习者 A”及数据均为从零编写的演示，不映射真实使用者，不含学校、职业或联系方式。

目标：在一个演示周内写出一页室内植物养护卡。完成证据是一张包括浇水、光照及观察方法的文字卡。

学习记录：原计划三次 20 分钟资料阅读；虚构记录显示完成两次，并整理了四条需要交叉核对的说法。投入时间不等于已掌握。

知识笔记：同一条养护建议可能受植物种类与环境影响。此处只演示如何写“来源待补、结论待验证”，不提供实际养护结论。

习惯记录：在早餐后观察叶片，每次两分钟；演示周记录了四次，其余日期未知，不据此判定失败。

反思：一次任务没开始；练习者自述材料太散。助手推断“先选一份材料可能降低启动成本”，标为待验证。

周复盘：卡片草稿已经完成，来源核对尚未完成。下周建议只安排一次来源核对；是否接受和执行均未报告。

Agent 工作流：只读取目标和上述学习记录，输出一条建议，不更新长期模型。提示词版本标记为 weekly-review v1。

新用户应复制空白模板到 private，避免在这里填入真实生活资料。

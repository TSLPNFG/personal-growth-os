# 日常工作流

## 每周规划

使用 [目标提示词](../prompts/goal-setting.md) 定义少量目标、完成证据、约束和停止条件。用 [学习规划](../prompts/learning-plan.md) 把一个目标拆成可完成的练习与产出。

## 行动与积累

学习后记录实际产出和卡点；知识笔记写清来源、自己的理解和一次应用。习惯按可观察行为记录，未记录不等于失败，不用连续天数推断人格。

## 反思与复盘

单次事件用 [反思提示词](../prompts/reflection.md)；每周用 [周复盘](../prompts/weekly-review.md)。比较计划与执行，选一个可检验调整，并说明下周如何判断效果。

## 记忆与归档

简单保存使用 Lite；要检验具体自我观察使用 Analyze；明确要求长期决策或阶段模型修正时使用 Deep。模式和长期记忆只在新证据确实改变理解时更新。规则见 [归档工作流](../rules/archive-workflow.md)。

## 提示词维护

把通用提示词放 prompts；带个人资料的版本放 private/workspace/prompts。用虚构输入比较版本，记录目标、输出质量与不足，不把一次表现当作普遍效果。

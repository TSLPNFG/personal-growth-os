# 架构

## 两种数据边界

公共层：规则、空白模板、提示词、虚构示例与工具。公共层不保存使用者资料。

私有层：`private/workspace/` 保存个人目标、学习记录、知识笔记、习惯、反思、个人提示词、决策、模式和记忆；`private/config.yaml` 保存偏好；`private/legacy/` 可保留旧项目；`private/audit/` 保存本地审计材料。

旧项目作为冻结档案保留原有内部相对链接；新记录使用新结构。不自动把旧摘要当成当前事实，也不批量重写原文。

## 信息流

目标 → 学习或习惯行动 → 实际产出与反馈 → 周复盘 → 下一轮目标。
知识笔记连接学习来源和应用；重要决定与候选模式通过相对链接引用证据，避免复制正文造成重复计数。

## 实现边界

当前实现是 Markdown 工作系统、Python CLI 和本地网页壳 App。配置 YAML 是人工/Agent 约定，CLI 和 App 不解析它；固定使用 private/workspace，不执行日历同步、定时提醒或数据库操作。

## 本地 App 分层

| 层 | 文件 | 职责 |
| --- | --- | --- |
| 启动 | Start-PGOS.ps1、app/server.py | 查找 Python，启动回环服务，打开 Edge 应用窗口或默认浏览器 |
| UI | app/ui/index.html、styles.css、app.js | 类型侧栏、时间线、筛选、Markdown 编辑、输入范围及草稿确认 |
| HTTP 边界 | app/server.py | 固定静态文件路由、Host/Origin/会话校验、请求长度限制、安全错误响应 |
| 数据 | app/storage.py | 复用模板、六类目录、路径校验、原子替换、版本冲突检查、实时搜索与统计 |
| 可选 AI | app/ai.py | 本机 Ollama 协议、模型本地性检查、内存输入快照及确认保存 |

Electron 的窗口、打包和系统集成更完整，但需要额外的 Node 工具链、IPC 和依赖维护。首版选择标准库 Python 服务加轻量网页壳，沿用已有工具和数据格式；暂不提供安装器或常驻托盘。

Pile 仅作为只读交互参考：类型侧栏、日期组织和独立写作区域。没有复制其代码、品牌、图标或资源，也没有复用密钥检查、索引同步与链接预览。当前搜索实时读取六类目录，不建立持久索引；正文按文本编辑，不执行 Markdown 内的 HTML、脚本、图片或外链预览。

新文件使用日期加随机标识命名，正文附可读的 pgos-date 注释及一级标题。原有 UTF-8 Markdown 可直接浏览；日期依次取注释、文件名日期或文件修改日期。标题从一级标题读取。文件没有必需的数据库或专有封装。

所有 API 使用不透明记录标识；客户端不提交任意文件路径。内存 AI 输入快照有效期为 15 分钟，只包含明确选中的 1–5 条记录。确认保存生成独立的 journal 文件，保留来源链接、输入版本和助手推断标签。

公共文件的唯一机器清单是 `config/public-files.json`。导出工具只复制清单文件，拒绝私有路径、链接、非文本内容及扫描发现，且不复用源仓库历史。
